# SIX Website Leadership Prototype

This folder contains the maintainable working prototype for the next SIX website and digital identity.

## Current prototype

- `index.html` — the Version 5 leadership-meeting build
- `assets/css/site.css` — responsive visual system
- `assets/js/site.js` — navigation, reveal effects and prototype interactions
- `assets/images/` — working concept photography and Kevin's intentional placeholder
- `assets/logos/` — current transparent SIX logo

## Prototype boundaries

- This is not the live `thesixshow.com` website.
- It does not sell tickets or publish performance dates.
- Ticket destination, schedule integration, final copy, approved photography, trailer media, reviews, awards and contact routing remain leadership decisions or verification tasks.
- Five brother portraits are working concept placeholders. Kevin's licensed/owned photograph is still needed.
- Public launch architecture is expected to move toward a maintainable WordPress staging build after concept approval.

## Preview

Open `index.html` in a browser, or serve this folder with any small static web server.
