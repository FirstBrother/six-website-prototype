## Historical handling rules

- Keep current-cast photography and historical-lineup photography explicitly
  separated.
- Never describe a historical lineup as the current SIX.
- Preserve the distinction between the authentic circa-1990 photograph and the
  later Charles-for-Curtis composite.
- Use approximate-date language such as "circa 1980" or "around 2000" until a
  program, contract, clipping, dated print, or other reliable source confirms
  the year.
- Do not overwrite these originals. Create separate derivatives for cropping,
  restoration, color correction, web optimization, or captioned treatments.
